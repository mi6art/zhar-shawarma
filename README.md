# Жар — шаурма с огнём

Демонстрационный сайт с тремя сценами приготовления, управляемыми прокруткой. Адаптивная версия для телефона и компьютера.

Название, меню и составы демонстрационные. Приём реальных заказов не подключён. Видеосцены созданы с помощью ИИ.

HTML, CSS и JavaScript без сборки. Для просмотра открыть index.html. Шрифты распространяются по SIL OFL; лицензии находятся в assets.
